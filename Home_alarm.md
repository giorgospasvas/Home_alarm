# Setup Guide

## Step 1: Create the Telegram Bot
- [ ] Open Telegram and search for `@BotFather`.
- [ ] Start a chat and send the command: `/newbot`
- [ ] Follow the prompts to give your bot a name and a username.
- [ ] Copy the HTTP API Token provided (`BOTtoken` in code).

## Step 2: Get Your Chat ID
- [ ] Search for `@IDBot` in Telegram and start a chat.
- [ ] Send the command: `/getid`
- [ ] Copy the numerical ID that it returns (`CHAT_ID` in code).
- [ ] **Crucial:** Open a chat with your newly created bot and press **Start**.
