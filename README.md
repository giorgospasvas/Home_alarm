#  A home alarm system  

An alert system using an ESP32 and an ultrasonic module .

## 🛠️ Components & Hardware
- **Microcontroller:** ESP32
- **Sensors:**  HC-SR04 Ultrasonic Sensor
- **Display:** Smartphone
- **Input:** TouchPin
